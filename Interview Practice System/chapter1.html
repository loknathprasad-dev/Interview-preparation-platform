Core Java

An introduction to the language, the platform, and how it all runs

01.1

What is Java?

Java is a high-level, object-oriented programming language originally released by James Gosling and his team at Sun Microsystems in 1995. Today, it is maintained and developed by Oracle Corporation. Java's defining strength is its "Write Once, Run Anywhere" (WORA) philosophy — code is written once and can run on any platform, including Windows, Linux, and macOS, without modification.

This is possible because Java source code does not compile directly into machine-specific instructions. Instead, it compiles into bytecode, which is executed by the Java Virtual Machine (JVM). Since every platform has its own JVM implementation, the same bytecode behaves consistently everywhere.

01.2

Key Features of Java

Platform Independent
Bytecode can run on any operating system through the JVM.
Object-Oriented
Everything is built around classes and objects — enabling reusable, organized code.
Simple & Secure
Removes complex features of languages like C++, such as manual memory management and pointers.
Robust
Strong memory management and built-in exception handling minimize runtime failures.
Multithreaded
Supports executing multiple tasks concurrently and efficiently.
Automatic Garbage Collection
Unused memory is reclaimed automatically, without manual intervention from the developer.

01.3

JDK, JRE, and JVM Explained

JVM (Java Virtual Machine) — The engine that converts bytecode into actual machine instructions and executes it. It is platform-specific.

JRE (Java Runtime Environment) — A combination of the JVM and core libraries, required simply to run a Java program.

JDK (Java Development Kit) — The JRE plus a compiler (javac) and debugging tools. This is what you need if you intend to write and compile Java code.

01.4

How Java Code Is Executed

Every Java program passes through the same sequence of steps before it runs:

Write .java file
→
Compile with javac
→
Generate .class bytecode
→
JVM executes it

01.5

Your First Java Program

Every Java developer's journey begins with the same program — printing "Hello, World!" to the screen:

public class HelloWorld {
  public static void main(String[] args) {
    System.out.println("Hello, World!"); // output print karega
  }
}

Let's break this down line by line:

  • public class HelloWorld — declares a class whose name must match the file name (HelloWorld.java).
  • public static void main(String[] args) — the entry point of every Java program. This is the method the JVM calls first.
  • System.out.println() — used to print text to the console.

01.6

Why Learn Java?

  • Android development — Java (along with Kotlin) forms the core foundation of Android app development.
  • Enterprise software — Java is heavily used in banking, e-commerce, and large-scale backend systems.
  • Job market — Java remains a stable, high-demand skill and has been an industry standard for decades.
  • Strong fundamentals — The object-oriented concepts Java teaches transfer directly to other languages such as C# and Python.
Tip: While learning Java, focus on understanding core concepts — classes, objects, and methods — rather than memorizing syntax. These fundamentals form the foundation for every chapter that follows.
